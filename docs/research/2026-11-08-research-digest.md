## Гол зарчим (гурвуулаа нэг зүйл хэлж байна)
- **Батлагдсан зүйлээ л амла.** Анхаарал ≠ conversion; хэт амлалт итгэлийг унагана.
- **Үндсэн мөчлөг эхэнд:** Өнөөдрийн дасгал → 20 с раунд → нэг зөвлөгөө → дахин раунд → ахиц.
  Дэлгүүр, social, marketplace үүнтэй өрсөлдөхгүй (судалгаа 1). Платформ v2-ийн дэлгүүр (QPay) —
  үндсэн мөчлөгийн KPI хэмжигдэх хүртэл **түр зогсоосон**.
- **«Мэргэжилтэнд сонирхолтой, шинэ хүнд ойлгомжтой, эхлэхэд аюулгүй»** (судалгаа 3).
- WCAG 2.2 AA (текст 4.5:1, UI 3:1, гар/фокус), Core Web Vitals p75: LCP ≤ 2.5 с, INP ≤ 200 мс, CLS ≤ 0.1.

## Аль хэдийн байсан (судалгаа «шалгаагүй» гэсэн)
- Ghost: CMU mocap (subject 14) + дасгалжуулагчийн өөрийн бичлэг, эх нь `lib/ghost/*.json`-д.
- Цохилтын eval: ангилал тус бүрийн F1, confusion matrix, phantom (`scripts/punch-eval`). Дутуу нь өгөгдөл:
  1 хүн, 6 клип (macro-F1 0.904) — 12–20 зөвшөөрөлтэй хүн хэрэгтэй.
- Итгэлцэл бага → «NOT ENOUGH DATA», `sessionConfidence`; бүртгэлгүй эхний раунд; камергүй таймер раунд.

## AI баталгаажуулалтын протокол (эзэмшигч + бид, хийгээгүй)
12–20 зөвшөөрөлтэй хүн, orthodox + southpaw, хэд хэдэн утас, гэрлийн 3 нөхцөл, камерын 2 байрлал,
удаан/ердийн/хурдан. Цохилтын эхлэл/төгсгөл, төрөл, гар, «хэмжих боломжгүй»-г тэмдэглэнэ. Train/test-ийг
**хүнээр** тусгаарлана. Хэмжүүр: ангилал тус бүрийн P/R/F1, confusion, давхар/алдсан тооллого,
false positive / минут, stance·төхөөрөмж·гэрлээр задалсан үр дүн, latency p50/p95, unscorable %,
дасгалжуулагч зөвшөөрсөн зөвлөгөөний %. Хүчийг физикийн нэгжээр хэзээ ч амлахгүй.
