# GAVANA аудит — 2026-11-08

Арга: код бүхэлдээ (54 route, ~400 component, ~120 lib) + утасны 390px дээр 16 дэлгэцийг
browser-оор нүдээр шалгасан. Гол мэдэгдлүүдийг кодоос дахин баталгаажуулсан (✔). Баталгаажаагүйг
"(шалгаагүй)" гэж тэмдэглэв. Код өөрчлөөгүй.

## Дүгнэлт

GAVANA-ийн цөм (камер → цохилт тоолох → оноо → AI зөвлөгөө → ахиц) ажилладаг, техникийн суурь
сайн (MediaPipe утсан дээрээ, 265 unit тест, 57 visual тест). Гэхдээ:

1. **Хэт олон зүйл.** Кодын ~45% (214 файл, 27.5k мөр) нь CORE_MODE-оор нуугдсан функцэд зориулагдсан.
   Нуугдсан хэрнээ зарим нь нэвтрэх замтай хэвээр.
2. **Тоонууд хоорондоо зөрдөг.** Нэг раунд хоёр өөр оноотой, XP гурван янзаар тоологддог,
   XP-ийн тайлбар сервертэй таардаггүй.
3. **Хэмжээгүй зүйлийг хэмжсэн мэт харуулдаг.** "Нарийвчлал/Хүч" баар, "X%-ийг ялсан",
   "83% Tank Davis" — бүгд онооноос гаргасан томъёо. Бодит хэрэглэгч үүнийг хурдан анзаарна.
4. **Нэр томьёо, хэл холилдсон.** Ижил ойлголт 3–6 нэртэй, MN дэлгэцэнд англи үг их.

Миний санал: шинэ функц нэмэхээ түр зогсоож, **"нэг үнэн тоо" долоо хоног** хийх —
хуурамч тоог устгах, оноо/XP-ийг нэг эх сурвалжтай болгох, нэр томьёог нэгтгэх. Дараа нь
хэрэггүй кодыг цэвэрлэх. Энэ хоёр нь шинэ 3D функцээс илүү итгэл нэмнэ.

**Устгах нэр дэвшигч:**

## 2. Хоорондоо уялдаагүй зүйлс

**Тоо**
- ✔ **Нэг раунд — хоёр оноо.** Үр дүнгийн карт итгэл бага үед оноог 7.5/8.5-д хязгаарладаг
  (`TrainResultModal.js:94`), харин хадгалсан оноо, toast, XP, түүх хязгаарлаагүй оноог ашигладаг.
- ✔ **XP тайлбар худлаа.** "оноо² × 10, өдөрт 1,000", "+200/+400 сайжруулалтын бонус",
  "like бүрт 2 XP", "Pro 2×" (`HowToEarnXP.js`) — сервер `оноо×35 + бонус`, сессэд ≤500,
  өдөрт 10 сесс өгдөг (`scoreGuard.js`). Бонус, like, Pro 2× огт олгогддоггүй.
- XP гурван янз: home/progress = хадгалсан + сесс + streak; sidebar, DNA түвшин, AI coach =
  зөвхөн хадгалсан; rank-up = зөвхөн хадгалсан. Streak тасрахад XP **буурч**, цол унаж болно.
- ✔ Desktop sidebar үргэлж "ROOKIE" гэж харуулна (`SidebarFooter.js:100` — `rank.label` байхгүй).
- Landing "60 секундын раунд" амладаг. Бодитоор: зочин/эхний удаа 20с, бүртгэлтэй 120с,
  ghost/bag/mitts 30с.
- "+50 XP CHALLENGE BONUS" харуулдаг, олгодог код алга (шалгаагүй, grep-ээр).
- "World Champion" нь цолны шатанд 25,000 XP, Combat Level-д 18,000 XP.

**Өгөгдөл**
- ✔ Радар статистик (Хурд/Хүч/Хамгаалалт/Нарийвчлал) `s.hits`-ийг уншдаг, сессэд `hitCount`
  хадгалагддаг → **үргэлж онооноос таамагласан** утга харуулна. "Хөлийн ажил" = streak.
- ✔ **Guard анхааруулга хэзээ ч ажилладаггүй**: pose код `too_low/too_high/good` гаргадаг,
  techniqueReview/combatProgress `"dropped"/"low"` шалгадаг.
- AI coach `fighterRank` уншдаг — хэн ч бичдэггүй. Onboarding-ийн `weeklyGoal` хадгалагддаг ч
  долоо хоногийн цагираг 5-аар хатуу кодлогдсон; `primaryInterest` хэн ч уншдаггүй.
- Хоёр live тоолуур: пикселийн детектор ("N хөдөлгөөн", "КОМБО") ба MediaPipe ("N цохилт").
- Uppercut шошго бий, детектор зөвхөн jab/cross/hook гаргадаг.

**Нэр томьёо / хэл**
- ✔ **Counter puncher-ийг "Тохой тулаанч"** (тохой = elbow) гэж бичсэн (`fighterDNA.js:22`,
  `archetypeTraining.js`, `coachConstants.js`); бусад газар "Контр".
- Хэв маягийн 2 өөр жагсаалт: onboarding {pressure, counter, technical, brawler},
  DNA {pressure, outboxer, counter, explosive, technician}. "Technical" сонгоход Pressure

  "Counter Striker", "Tank Davis 83% match").
- Нэг archetype 3 өөр өнгөтэй (quiz алт, DNA ягаан, profile цэнхэр).
- Streak = дараалал / Давтамж / Стрийк / Залгамж / streak. Jab = "жааб" (~120) ба "жэб" (~115).
  Coach = Коуч / AI Дасгал / Чиний булан / AI дасгалжуулагч / AI коуч.
- MN дэлгэцэнд англи: sidebar бүхэлдээ, "WORLD TOUR", "GHOST ROUND · JAB-CROSS", "Train руу
  буцах", "PUNCHES", "MAX SPEED", "YOU'RE IN", "First Punch", "Эрж ре-сет хий!".

## 4. Ашиглахад хүндрэлтэй

1. ✔ **Шинэ хэрэглэгч эхний 3 үр дүнгээ хардаггүй.** Хадгалсны дараа `FirstSessionHook`
   (zIndex 9999) оноо, засвар, AI дебрифийг бүрхэнэ; "Дахин бэлтгэл" товч үр дүнг арилгана.
2. **Попап давхарладаг:** toast + badge + DNA share sheet (1.5с) + hook + milestone +
   push-permission banner (6с).
3. **Нэг раундад "засах нэг зүйл" 4 удаа:** дүрмийн зөвлөгөө, AI дебриф, ReturnSummary
   (англиар), өдрийн даалгавар.
4. **Эхний раунд хүртэл урт:** бүртгэлтэй — onboarding 5 дэлгэц → Start → readiness modal →
   countdown. Зочин — overlay "Байрлалаа сонго" гэдэг ч сонгох товчгүй; overlay хаагдсаны
   дараа 1.4с-д раунд автоматаар эхэлж, камерын зөвшөөрөл overlay-ийн ард гарна.
5. **Train дэлгэц хэт ачаалалтай:** 9 хүртэл карт, техник сонгогч, stance, Start,
   Ghost/Mitt/Bag, чирэгддэг даалгаврын товч, ижил раунд эхлүүлэх 4 нэмэлт товч.
6. **Jargon:** DNA, XP, Ghost, streak, archetype, Ring IQ, combo, slip — тайлбаргүй.
7. Жижиг товч (<40px): "Судлах" (~28px), DNA toast "→", readiness "алгасах",
   "Раундын дэлгэрэнгүй", "Pro →". 30–40% тунгалаг 11px текст.
8. Mitt-ийн хариу үйлдлийн хугацаа ms-ээр — ~80ms алдаатай.

## 5. Засах дараалал (санал)

**A. Итгэл (1–2 өдөр, эрсдэл бага)**
1. Хуурамч тоог устгах: telemetry баар, "ЯЛСАН %", "2,400+", "% match", урьдчилсан DNA хувь,
   ai-analysis-ийн random оноо.
2. AI prompt: "тооцоолж зохио" → "зөвхөн өгсөн тоог ашигла".
3. "ТРЕНЕРИЙН ДҮГНЭЛТ" → "Автомат дүгнэлт"; "Тохой тулаанч" → "Контр тулаанч".
4. Нууцлалын бодлого ↔ `coach_memory` зөрчлийг засах (бодлогыг засах уу, хадгалахаа болих уу —
   таны шийдвэр).
5. "Мэдэгдэл авах" товч, Pro-г checkout ажиллах хүртэл нуух.
6. Landing-ийн "60 секунд"-ийг бодит хугацаатай тааруулах.

**B. Нэг үнэн тоо (2–3 өдөр)**
7. Нэг оноо (cap-тай эсвэл cap-гүй — нэгийг нь) бүх газар.
8. XP: нэг томъёо (сервер), `HowToEarnXP`-ийг сервертэй тааруулах, streak-ээс XP хасагдахгүй болгох.
9. Радар `hitCount`-ийг уншдаг болгох; guard `too_low` → анхааруулга ажиллуулах.
10. Live тоолуур нэг (MediaPipe).

**C. Ойлгомжтой байдал (2–3 өдөр)**
11. Хэв маягийн нэг жагсаалт + нэг өнгө; streak/jab/coach нэг үг; MN-ийн англи шошгыг орчуулах.
12. Раундын дараа нэг л баяр/попап; FirstSessionHook-ийг үр дүнгийн дараа.
13. Train дэлгэцийг хялбарчлах (Start + 1–2 нэмэлт горим).

**D. Цэвэрлэгээ (1 өдөр)**
14. `/reels` bypass, gym товч, coach marketplace-ийг CORE_MODE-д нуух.
15. Үхсэн файл/export, `messages/`, svg, README conflict устгах; RankUp modal нэгтгэх.
