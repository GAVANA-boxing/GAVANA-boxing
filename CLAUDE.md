# GAVANA Boxing — Claude Instructions

## User Language: Mongolian
The user communicates in Mongolian. Below are their common commands and what they mean.

### Command Glossary

| Mongolian | Meaning | Action |
|---|---|---|
| **Hii** | "Do it" | Implement the last discussed thing immediately |
| **Bugdiin hii** / **Bugdiig ni hii** | "Do all of them" | Implement everything listed/discussed |
| **Okay** | "Proceed" | Continue with the plan |
| **Hiiysgeey** | "Let's do it" | Start implementing |
| **Duustsan uu?** | "Is it done?" | Check if current task is complete |
| **Daraagiin phase yu we?** | "What is the next phase?" | Ask what comes next |
| **Chi yu hiij baina** | "What are you doing?" | Explain current task |
| **Shalga** | "Check it" | Investigate/verify something |
| **Tegwel** | "Then / So" | Transition word — "so what's next?" |
| **Iimerhuu** | "Like this / This kind of" | Referring to something just shown |
| **Iim zowolgoo awlaa** | "I received this advice" | User sharing external advice to consider |
| **Dugnelt hiigeed ooriinhoo sanaag heleech** | "Give your summary and opinion" | Summarise and give recommendation |
| **Chi minii… medej baigaa bisdee** | "You already know… right?" | Rhetorical — confirming shared context |

### Behaviour Rules
- When the user says **Hii**, implement immediately without asking clarifying questions.
- When the user says **Bugdiin hii**, do everything on the list in one go.
- Keep responses short and direct — the user does not want long explanations unless asked.
- Always develop on branch `claude/review-refactor-code-DUmiX` and push after each change.
- Do not create pull requests unless explicitly asked.
